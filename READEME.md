<p align="center"><strong>Fast. Expressive. Native.</strong></p>

Marshmellow is a lightweight, unofficial native Discord client built with Rust and egui.
It combines a Material 3 Expressive interface with bounded caches and spring-driven motion.

## Highlights

- Material 3 Expressive colors, typography, icons, and spring animations
- Native desktop experience with low idle resource use
- Offline demo mode for safe interface testing
- Linux zip install, update, and uninstall helpers

## Quick start

```sh
cargo run --locked -p serein --features demo -- --demo
```

See [README.md](README.md) for build dependencies, packaging, and platform support.
